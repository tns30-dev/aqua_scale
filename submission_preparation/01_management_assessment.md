# 01 Management Assessment

Rubric: Assessment Rubrics I
Duration: 5 minutes
Cloud dependency: Low

## What This Video Must Prove

- The project has a clear justification, not just a technical migration.
- The second submission extends the first submission with cloud-native microservices, DevSecOps evidence, IoT integration, and large telemetry storage.
- The scope is controlled and mapped to completed user stories/use cases.
- The work was managed through agile tracking, sprint goals, backlog completion, effort tracking, and issue mitigation.

## Required Rubric Points

- Project justification
  - Project goals defined.
  - Pain points and reasons for enhancement explained.
  - Benefits to the user and sponsor explained.
- Project scoping
  - Project journey map.
  - Scope, features, and use cases.
  - Product backlog.
- Project conduct
  - Scrum practices.
  - Tracking tool evidence.
  - Sprint backlog evidence.
  - Completed user stories, sprint goals, and burndown charts.
- Project effort
  - Overall effort in man-days.
  - Planned hours versus actual hours.
- Management issues and mitigation
  - Cloud cost pressure.
  - Technical risk from monolith-to-microservice migration.
  - Integration risk across GCP, AWS IoT, Firebase, GitHub Actions, and Kubernetes.

## Suggested Speaker Notes

- Start with the problem: shrimp pond monitoring needs reliable real-time visibility, historical analysis, and operational decision support.
- Explain the first submission baseline: monolith application with core features.
- Explain the second submission goal: transform into a cloud-native microservice platform with stronger scalability, DevSecOps, and production-style deployment.
- Mention that cloud cost was actively managed by prioritizing live cloud evidence capture, then moving lower-risk documentation and design work offline.
- Close by connecting project management evidence to delivery: backlog, sprints, test evidence, deployment evidence, and final demonstration.

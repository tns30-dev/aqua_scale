### Body — stack table, grouped by layer

#### 🔌 IoT Edge

| Component | Choice | Why |
|---|---|---|
| Sensor host | **Raspberry Pi** | Cheap, ARM-class compute, runs Linux + Python out of the box; offline buffering when network drops |
| Edge protocol | **MQTT** (Mosquitto broker) | Lightweight pub/sub built for unreliable networks; standard in IoT |

#### 📡 Real-time Pipeline

| Component | Choice | Why |
|---|---|---|
| WebSocket framework | **Django Channels** | Keeps the entire backend in one framework (no separate Node/Go service for sockets) |
| Channel layer | **Redis** | Fast pub/sub between MQTT adapter, ASGI workers, and connected browsers; horizontal-scale ready |
| ASGI server | **Daphne** | Channels-native ASGI server — runs HTTP + WebSocket on one process |

#### 🐍 Backend

| Component | Choice | Why |
|---|---|---|
| Web framework | **Django 5.2** + **Django REST Framework** | Mature ORM, admin panel, auth primitives — fits a research-led project that needs to move fast on schema changes |
| API documentation | **drf-spectacular** | Auto-generates OpenAPI 3 schema; consumed by the SPA's typed client |
| Admin styling | **django-unfold** | Modern UI on top of Django Admin for the platform admin's daily workflow |
| Auth | **djangorestframework-simplejwt** in HttpOnly cookies | JWT signed locally (no IdP round-trip); HttpOnly + CSRF closes the XSS exfiltration path |
| Language | **Python 3.12** | Matches Django 5.2's supported runtime; type hints throughout |

#### ⚛️ Frontend

| Component | Choice | Why |
|---|---|---|
| Framework | **React 19** + **TypeScript** | Component model + strict types; matches the team's existing React experience |
| Bundler | **Vite 7** | Fast HMR in dev; modern build pipeline; first-class TS support |
| UI primitives | **shadcn/ui** + **Radix** + **Tailwind CSS** | Accessible primitives + utility classes — design system without a heavyweight component library |
| Routing | **react-router-dom 7** | Standard SPA routing |
| State | **Zustand** | Lighter than Redux; matches the project's modest global-state needs |
| Forms | **react-hook-form** + **Zod** | Schema-first form validation; Zod schemas double as API contract types |
| Charts | **Recharts** | Declarative React-native charts for the historical-trends + comparison views |
| Tables | **@tanstack/react-table** | Headless table primitives for the user-mgmt + sensor admin grids |

#### 🗄️ Data & Persistence

| Component | Choice | Why |
|---|---|---|
| Database | **PostgreSQL 15** | JSONB for `feature_access` + `action_control`; native UUID, composite primary keys, partitioning for sensor readings |
| Driver | **psycopg2** | Standard, supports COPY + cursor batching |
| Schema strategy | **Database-first (`managed = False`)** | SQL is the source of truth; Django models mirror it without owning migrations — gives the consultant single-file schema review |

#### 🔐 Security

| Component | Choice | Why |
|---|---|---|
| Auth model | **HttpOnly JWT cookies** + **CSRF double-submit** | Defends against XSS exfiltration and CSRF in the same model |
| SAST (Python) | **Bandit** | Catches insecure defaults in source (assert in prod, weak hashes, etc.) |
| SAST (JS/TS) | **Semgrep** (default + OWASP top-10 + React rules) | Cross-language ruleset; SARIF output for CI visibility |
| SCA (Python) | **pip-audit** | OSV database; fails on high/critical CVEs |
| SCA (JS/TS) | **npm audit** | Native to the toolchain; fail-on-high gate |
| DAST | **OWASP ZAP baseline** | Black-box scan against the running app; finds headers, cookie attrs, info leak |

#### ⚙️ CI/CD & Quality

| Component | Choice | Why |
|---|---|---|
| CI runner | **GitHub Actions** | Tight integration with the repo; matrix jobs for FE + BE |
| Backend tests | **pytest** + **pytest-django** | Standard Django testing; coverage via pytest-cov |
| Frontend unit | **Vitest** | Vite-native test runner; reuses the build's transform pipeline |
| E2E | **Playwright** | Cross-browser, request mocking via `page.route` so e2e doesn't need the backend |
| Load + Stress | **k6** | JS-scripted, fails CI when latency/error thresholds are crossed |
| Lint (BE) | **Ruff** | Fast (Rust); replaces flake8 + isort + pyupgrade in one tool |
| Lint (FE) | **ESLint** + **typescript-eslint** | Standard for TS projects |
| Type check | **tsc** (FE), **mypy** + **django-stubs** (BE, local-only) | Static type safety before runtime |

#### ☁️ Infrastructure & Hosting

| Component | Choice | Why |
|---|---|---|
| IaC | **Terraform** + **Google provider** | Declarative infra; GCS-backed remote state; one `apply` to recreate the demo environment |
| Demo runtime | **GCP Cloud Run** | Containerised, scale-to-zero, $0 between rehearsals |
| Container registry | **GCP Artifact Registry** | Native to Cloud Run; per-image IAM scoping |
| Managed DB | **GCP Cloud SQL (Postgres 15)** | Matches the local schema 1:1; backups + point-in-time recovery available |
| Secrets | **GCP Secret Manager** | Cloud Run pulls JWT key, DB password, Django secret at runtime via `--set-secrets` |
| Containers | **Docker** | Per-image immutability; same image dev → CI → Cloud Run |

## Speaker notes (≈ 60–90s — say out loud, don't put on slide)

> "Quick tour of the stack, grouped by what it does.

> **At the edge**, sensors talk to a Raspberry Pi over GPIO/serial; the Pi publishes to **Mosquitto MQTT**. We chose MQTT because it's built for unreliable networks — the Pi buffers and retries when the broker is unreachable.

> **The real-time pipeline** is **Django Channels** on **Daphne** with **Redis** as the channel layer. That means HTTP and WebSocket run on the same Django process, and Redis lets us scale to multiple workers later without a rewrite.

> **The backend** is **Django 5.2** with **DRF** for the JSON API, **simplejwt** for auth issued as **HttpOnly cookies**, and **drf-spectacular** auto-generating the OpenAPI schema the SPA consumes. Schema-first via **`managed=False`** — the consultant reviews SQL files, not migrations.

> **The frontend** is **React 19 with TypeScript** on **Vite**, **shadcn/ui** for design-system components, **Zustand** for state, **react-hook-form + Zod** for forms, and **Recharts** for the historical trends and comparison views.

> **Database** is **Postgres 15** — JSONB for the feature-access permissions blob, composite primary keys for user-project links, partitioning for high-volume sensor readings.

> **Security** is a layered set: HttpOnly cookies plus CSRF for the runtime model, **Bandit** and **Semgrep** for static scanning, **pip-audit** and **npm audit** for dependency CVEs, **OWASP ZAP** for dynamic scanning in CI.

> **CI/CD** runs in **GitHub Actions** — pytest, Vitest, Playwright, k6 load and stress, all on every PR.

> **Hosting** for the demo is **GCP Cloud Run + Artifact Registry + Cloud SQL**, provisioned via **Terraform**. Cloud Run scales to zero between rehearsals so the demo environment costs almost nothing when idle."
